# 🎮 Playroom 관리 웹사이트

토요일 플레이룸에 입장한 학생에게 **입장 시점부터 1시간 30분**의 이용 시간을 주고, 관리자가 시간을 관리하면서 알림을 받고, 학생은 이름으로 남은 시간을 조회하는 웹사이트입니다.

- **Netlify 무료 플랜**에 올려서 씁니다. 인터넷 주소가 생기므로 학생은 어떤 와이파이에서든, 휴대폰 데이터로도 접속할 수 있습니다.
- 데이터는 Netlify Blobs(Netlify 기본 저장소)에 저장되어 계속 유지됩니다.
- 관리자 비밀번호는 처음 접속할 때 화면에서 정합니다. 따로 설정할 것은 없습니다.

## 기능

| 구분 | 기능 |
| --- | --- |
| 구역 지정 | 호수 입력 + 남/여 타입 지정, 수정·삭제 (이용 중인 학생이 있으면 삭제 불가) |
| 학생 배정 | 구역 카드에 이름 입력 → **입장**을 누르는 순간부터 90분 카운트다운 시작 |
| 시간 관리 | 정지/재개, −5분 / +5분 / +10분, `⋯` 메뉴에서 원하는 만큼 분 단위 조정·구역 이동 |
| 알림 | 시간이 0이 되면 **브라우저 알림 + 경고음 + 상단 빨간 배너 + 탭 제목 깜빡임**. 퇴실 처리 전까지 1분마다 경고음 반복 |
| 퇴실 | 퇴실 버튼 → 퇴실 처리 (시간이 남은 학생은 확인창 표시) |
| 기록 | 그날 이미 입장한 학생은 다시 입장 불가 (퇴실 후에도). 띄어쓰기만 다른 이름(`홍 길동`/`홍길동`)도 같은 학생으로 판단. 날짜별 기록 조회 |
| 학생 조회 | 메인 페이지에서 이름 검색 → 방, 남은 시간, 정지 여부 확인. 마지막으로 검색한 이름 자동 기억 |

- 잘못 등록한 경우 **기록 → 삭제**를 하면 같은 날 다시 등록할 수 있습니다.
- 시간이 끝난 뒤에 시간을 추가하면 "지금부터" 계산됩니다. 이미 넘긴 시간만큼 깎이지 않습니다.
- 날짜는 한국 시간(Asia/Seoul) 자정을 기준으로 바뀝니다.
- 기록은 약 1년(400일)이 지나면 자동으로 정리됩니다.

## 주소

- 학생 조회: `https://<사이트이름>.netlify.app/`
- 관리자: `https://<사이트이름>.netlify.app/admin`

## 배포 (처음 한 번만)

1. [Netlify](https://app.netlify.com)에 GitHub 계정으로 가입합니다.
2. **Add new project → Import an existing project → GitHub** → `playroomAdmin` 저장소를 선택합니다.
3. 설정은 `netlify.toml`에 다 들어 있으므로 아무것도 바꾸지 말고 **Deploy**를 누릅니다.
4. 배포가 끝나면 `https://<사이트이름>.netlify.app/admin`에 **바로 접속해서** 관리자 비밀번호를 정합니다.
   - 처음 접속한 사람이 비밀번호를 정하는 방식이므로, 학생에게 주소를 알려주기 전에 먼저 설정하세요.
5. 사이트 이름은 Netlify의 **Project configuration → Change project name**에서 바꿀 수 있습니다 (예: `our-playroom` → `our-playroom.netlify.app`).
6. 학교 와이파이에서 주소가 열리는지 한 번 확인하세요. 일부 학교망은 모르는 사이트를 막기도 합니다.

### 비밀번호를 잊어버렸을 때

Netlify → **Project configuration → Environment variables**에서 `ADMIN_PASSWORD`를 추가하고 다시 배포하면, 그 값이 새 비밀번호가 됩니다. 환경변수가 있으면 화면에서 정한 비밀번호보다 우선합니다.

### 선택 설정 (환경 변수)

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `ADMIN_PASSWORD` | 없음 | 설정하면 화면에서 정한 비밀번호 대신 이 값을 사용 |
| `DURATION_MINUTES` | `90` | 기본 이용 시간(분) |
| `TIME_ZONE` | `Asia/Seoul` | "같은 날"을 판단하는 시간대 |

## 무료 플랜 사용량

Netlify 무료 플랜은 월 300크레딧이고, 다 쓰면 그 달에는 사이트가 멈춥니다.

- 화면은 몇 초마다 서버에 새 정보를 물어봅니다 (관리자 5초, 학생 15초). 화면이 보이는 동안에만 물어보므로, 토요일 하루에 몇 크레딧 정도만 씁니다.
- **크레딧을 가장 많이 쓰는 건 배포입니다 (1회 15크레딧).** `main` 브랜치에 코드가 합쳐질 때만 배포되니, 수정 사항은 모아서 한 번에 합치는 것이 좋습니다.

## 브라우저 알림 체크리스트

1. 관리자 페이지 상단의 노란 안내에서 **알림 켜기**를 누르고 허용 → 테스트 알림이 뜨는지 확인합니다.
2. Windows: 설정 → 시스템 → 알림에서 Chrome 알림 켜기 / macOS: 시스템 설정 → 알림 → Chrome 허용
3. 관리자 탭은 닫지 마세요. 다른 탭으로 넘어가 있으면 알림이 최대 1분 정도 늦을 수 있습니다 (브라우저가 숨겨진 탭의 타이머를 늦추기 때문). 관리자 화면을 앞에 띄워두면 바로 울립니다.
4. 아이패드 Safari는 웹 알림을 지원하지 않습니다(홈 화면에 추가한 경우 제외). 이 경우 화면 배너와 경고음으로 알려줍니다.

## 로컬 실행 (개발·테스트용)

Node.js 20 이상이 필요합니다. 데이터는 `data/playroom.json`에 저장됩니다.

```bash
npm start
```

```bash
npm test
```

```
netlify.toml                  Netlify 배포 설정
netlify/functions/api.mjs     Netlify 함수 진입점 (/api/*)
src/netlify.js                Blobs에서 읽고 → 처리 → 충돌 없을 때만 저장 (충돌 시 재시도)
src/api.js                    API 라우팅 (로컬 서버·Netlify 공용)
src/store.js                  구역·입장 기록·타이머 규칙
src/auth.js                   관리자 비밀번호·로그인 쿠키(HMAC 서명)·로그인 시도 제한
src/app.js, server.js         로컬 실행용 Node 서버
public/                       학생 페이지(index.html), 관리자 페이지(admin.html)
test/                         단위·API·Netlify 핸들러 테스트 (node:test)
```

타이머는 서버가 1초마다 숫자를 깎는 방식이 아니라, **종료 시각(endAt)** 을 저장해두고 각 화면이 남은 시간을 계산합니다. 그래서 새로고침하거나 기기를 바꿔도 시간이 어긋나지 않습니다.
