# 🎮 Playroom 관리 웹사이트

토요일 플레이룸에 입장한 학생에게 **입장 시점부터 1시간 30분**의 이용 시간을 주고, 관리자가 시간을 관리·알림 받고, 학생은 이름으로 남은 시간을 조회하는 웹사이트입니다.

- **외부 라이브러리 0개** — Node.js만 있으면 `npm install` 없이 바로 실행됩니다.
- 데이터는 `data/playroom.json` 파일 하나에 저장됩니다 (DB 설치 불필요).
- 관리자 화면과 학생 화면은 실시간으로 동기화됩니다 (Server-Sent Events).

## 기능

| 구분 | 기능 |
| --- | --- |
| 구역 지정 | 호수 입력 + 남/여 타입 지정, 수정·삭제 (이용 중인 학생이 있으면 삭제 불가) |
| 학생 배정 | 구역 카드에 이름 입력 → **입장** 누르는 순간부터 90분 카운트다운 시작 |
| 시간 관리 | 정지/재개, −5분 / +5분 / +10분, `⋯` 메뉴에서 임의 분 단위 조정·구역 이동 |
| 알림 | 시간이 0이 되면 **브라우저 알림 + 경고음 + 상단 빨간 배너 + 탭 제목 깜빡임**. 퇴실 처리 전까지 1분마다 경고음 반복 |
| 퇴실 | 퇴실 버튼 → 퇴실 처리 (시간이 남은 학생은 확인창 표시) |
| 기록 | 같은 날 이미 입장한 학생은 중복 입장 불가 (퇴실 후에도). 띄어쓰기 차이(`홍 길동`/`홍길동`)도 같은 학생으로 판단. 날짜별 기록 조회 |
| 학생 조회 | 메인 페이지에서 이름 검색 → 방, 남은 시간, 정지 여부 실시간 확인. 마지막 검색 이름 자동 기억 |

- 잘못 등록한 경우 **기록 → 삭제**를 하면 같은 날 다시 등록할 수 있습니다.
- 시간 종료 후 시간을 추가하면 "지금부터" 추가됩니다 (이미 넘긴 시간만큼 깎이지 않음).
- 날짜 기준은 한국 시간(Asia/Seoul) 자정입니다.

## 주소

- 학생 조회: `/`
- 관리자: `/admin`

## 실행 방법

### A. 관리자 노트북에서 바로 실행 (가장 간단)

[Node.js](https://nodejs.org) 20 이상을 설치한 뒤:

```bash
npm start
```

콘솔에 관리자 비밀번호와 학생용 주소(`http://192.168.x.x:3000`)가 출력됩니다.

- 관리자는 **반드시 그 노트북에서 `http://localhost:3000/admin`** 으로 접속하세요. 브라우저 알림은 보안상 `localhost` 또는 HTTPS 주소에서만 동작합니다.
- 학생은 같은 Wi-Fi에서 출력된 `http://192.168.x.x:3000` 주소로 접속합니다. (QR 코드로 만들어 붙여두면 편합니다.)
- 데이터는 `data/` 폴더에 남아 서버를 껐다 켜도 유지됩니다.

### B. 인터넷에 배포 (Render, 무료)

1. [Render](https://render.com) 가입 → **New → Blueprint** → 이 GitHub 저장소 선택 → Apply
2. 배포가 끝나면 서비스의 **Environment** 탭에서 자동 생성된 `ADMIN_PASSWORD`를 확인
3. `https://<서비스이름>.onrender.com/admin` 으로 접속

> 무료 플랜은 15분간 접속이 없으면 잠들고, 재시작 시 저장 파일이 초기화됩니다. 관리자 페이지를 열어두면 연결이 유지되어 잠들지 않으므로 **토요일 운영 중에는 문제 없지만**, 구역 목록이 주마다 사라질 수 있습니다. 유지가 필요하면 유료 플랜에서 Disk를 추가하고 `DATA_DIR`을 그 경로로 지정하세요.

### C. Docker

```bash
docker build -t playroom .
```

```bash
docker run -d -p 3000:3000 -v playroom-data:/data -e ADMIN_PASSWORD=원하는비번 playroom
```

## 설정 (환경 변수)

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `ADMIN_PASSWORD` | 자동 생성 | 관리자 비밀번호. 비워두면 처음 실행 시 생성해서 `data/admin-password.txt`에 저장 |
| `DURATION_MINUTES` | `90` | 기본 이용 시간(분) |
| `PORT` | `3000` | 서버 포트 |
| `DATA_DIR` | `./data` | 데이터 저장 폴더 |
| `TIME_ZONE` | `Asia/Seoul` | "같은 날" 판단 기준 시간대 |

## 브라우저 알림 체크리스트

1. 관리자 페이지 상단 노란 안내의 **알림 켜기** 클릭 → 허용 → 테스트 알림이 뜨는지 확인
2. Windows: 설정 → 시스템 → 알림에서 Chrome 알림이 켜져 있는지 / macOS: 시스템 설정 → 알림 → Chrome 허용
3. 관리자 탭은 **닫지 말고** 다른 탭이나 창으로 전환해 두면 됩니다. (서버가 0초가 되는 순간 이벤트를 보내므로 백그라운드 탭에서도 바로 울립니다)
4. 아이패드 Safari는 웹 알림을 지원하지 않습니다(홈 화면에 추가한 경우 제외). 이 경우 화면 배너·경고음으로 알려줍니다.

## 개발

```bash
npm test
```

```bash
npm run dev
```

```
server.js          진입점 (환경 변수, 비밀번호, 서버 시작)
src/store.js       구역·입장 기록·타이머 로직과 파일 저장
src/auth.js        관리자 로그인 쿠키(HMAC 서명), 로그인 시도 제한
src/app.js         HTTP 라우팅, SSE, 정적 파일
public/index.html  학생 조회 페이지
public/admin.html  관리자 페이지
public/js/notify.js 알림·경고음·제목 깜빡임
test/              단위·API 테스트 (node:test)
```

타이머는 서버가 1초마다 숫자를 깎는 방식이 아니라 **종료 시각(endAt)** 을 저장하고 각 화면이 계산합니다. 서버가 재시작되거나 화면을 새로고침해도 시간이 어긋나지 않습니다.
